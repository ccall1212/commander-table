# Moderation and recovery — v0.34.0 test copy

Download, extract and double-click **index.html**. Keep internet access on. No terminal/local server needed. Use four players on this copy: host, delegate, board owner and empty replacement player.

## Click list

1. Right-click a player's name as host → Grant moderator permissions. As delegate, verify Restore to game (undo concede), Kick and Transfer menus appear; a normal member should not get those controls. Only the host grants/revokes permissions. Revoke and confirm delegate loses those controls.
2. Start a game, concede as a guest, then restore them as host/delegate. They should re-enter turn eligibility without rewinding played turns. Try restoring the active player's concession and an all-conceded table too.
3. Close a guest's active tab (confirm leaving), then open a new tab in that same browser. Dismiss the resume reminder and click Join for the same room. Resume seat should restore the same private hand/library/board without another participant appearing. Dismiss must keep the save. Joining with the same name from another browser should be rejected and explain resume/moderator recovery.
4. On an active owner's board, play cards, adjust life/P/T/counters, and reveal a hand card/top card if desired. As moderator → Transfer this board… → choose an empty replacement seat and confirm. It replaces their current private board, keeps a local recovery copy and saved deck, moves card/commander/attachment references, removes the old seat, and preserves private hand/library order. The recipient must have an empty battlefield/graveyard/exile and no cards controlled elsewhere. Host's own board cannot be the source; host may receive if its board meets the empty-seat conditions.
5. Reload the recipient, then start a new game: the transferred deck should still work. Check Sidebar/Grid around 1920×1080 and 1366×768. Handoff clears prior undo and targeting arrows so old state cannot resurrect transferred cards.
6. For disconnected recovery, use a separate seat in the browser holding the owner's still-saved session/deck, then have a moderator transfer the disconnected board to that seat. Without the private saved data, stop with an explanation and leave seats intact. Test cancelled handoffs or unavailable recipient storage without seat loss.
7. Kick a guest as delegate. They should return to the lobby, and their removed identity must not re-seat on reconnect. Host cannot be kicked. Verify other players still play normally. Delegating moderation does not replace the network host; host reconnect/resume remains necessary after a host disconnect.
