# Admin Spectate view fix — v0.50.1 test copy (Objective #52)

The v0.50.0 code is live. Extract the v0.50.1 test ZIP and double-click `index.html` to test this fix against a live relay room. Chris confirmed Spectate works after the relay deployment caught up, then reported that the host's miniature turned grey when viewing another player's board. This copy fixes that miniature in Spectate and regular games and improves the old-relay error screen; see [admin setup](docs/ADMIN.md).

1. On the lobby, confirm no Admin link is visible. Click the **Tree of Life**, **Dragon Flame**, **Obsidian Gem**, then **Gilded Knight** card backs. A small Admin link should appear. An out-of-order click should reset the sequence. The selected card back should still change normally. Open the link; a wrong passphrase should not reveal rooms.
2. With two players in a relay room, sign into the dashboard and choose **Spectate**. In Sidebar, click the other player's miniature to view their board. The host's miniature at the right should retain its playmat and public cards and should not say **YOU**. Click the host miniature to switch back. In Grid, the host quadrant should also retain its playmat and cards without a **YOU** tag. The admin should not take a player seat or appear in the roster. Publicly revealed cards should remain visible; unrevealed hands and libraries should show backs/counts only.
3. As a regular player in the same room, view the other player's board in Sidebar. Your own miniature should retain its playmat and cards, still say **YOU**, and click back to your board. Check Grid too. Arrows should still follow the cards when switching views.
4. In the spectator view, try clicking, dragging and using the normal game hotkeys. Nothing should change in either player's game. The layout buttons, log, chat viewing and **Admin rooms** link should work. Reload the spectator tab and check it resumes from the current public snapshot without asking for a deck or player color.
5. Close or disconnect the host and confirm Spectate reports that the relay host is unavailable. Check that direct PeerJS fallback rooms remain absent from the dashboard. This feature does not show private recovery backups.
